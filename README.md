
# Anca C. Micu, PhD — Static Website

This is a GitHub Pages–ready static website.

## Files
- `index.html` — homepage
- `expertise.html` — AACSB / AI expertise page with working calculators
- `publications.html`
- `about.html`
- `contact.html`
- `assets/css/styles.css`
- `assets/js/site.js`
- `assets/images/*`

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder.
6. Save.

## Contact form
The contact form is configured for `formsubmit.co` so it can work on a static site without custom backend code.
After the first submission, FormSubmit may send a confirmation email to activate the form delivery.
